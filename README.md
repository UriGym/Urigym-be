# Urigym Backend

안녕하세요! **우리짐(Urigym)** 백엔드 프로젝트입니다.

## 프로젝트 소개

우리짐은 내 주변 체육관을 찾고 관리할 수 있는 서비스입니다.

- 체육관 검색 및 조회
- 회원가입 / 로그인 (JWT 인증)
- 출석 체크
- 리뷰 작성
- 관장용 대시보드

## 기술 스택

- Java 17
- Spring Boot 3.4
- Spring Security + JWT
- Spring Data JPA
- PostgreSQL
- Gradle

## 실행 방법

```bash
# PostgreSQL 실행 필요
./gradlew bootRun
```
